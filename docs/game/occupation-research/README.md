# AI 개발용 직업 조사 자료

552개 직업을 동일한 항목으로 조사하고 확인된 사실·현직자 사례·게임 창작을 구분해 보관한다. NCS는 사용하지 않는다.

## 파일

- `occupations.jsonl`: 직업별 공식 업무·준비 경로, 보강한 역량·지식·관련 자격 링크·탐색 활동, 인터뷰 연결 후보 및 검토 결과. 한 줄이 한 직업이다.
- `progress.json`: 단계별 실제 진행 수. `deep_research_complete`가 심화조사 완료 수다.
- `PROGRESS.md`: 552개 전체의 읽기용 진행표.
- `REVIEWED.md`: 직접 검토한 직업의 읽기용 조사 노트.
- `interview-lookup-log.jsonl`: 전체 공식 인터뷰 목록에서 직업 코드를 대조한 기록과 검색 한계.
- `manual-reviews.json`: 직접 검토한 업무 설명과 근거, 미확인 사항, 게임 상황 예시.

## AI에 전달하는 기준

일반 업무는 신입의 독립 수행 권한을 뜻하지 않는다. `review`에서 확인한 부분과 공식 업무·준비 정보를 구분해 검색한다. `interview_candidates`는 출판자의 관련 직업 코드로 연결한 후보이며, `body_review.classification`이 `direct` 또는 `specialty`일 때만 해당 직업의 보조 사례로 검색한다. `direct`는 직업과 인터뷰 본문 속 업무가 직접 일치하고, `specialty`는 같은 직업군의 특정 분야·직급 경험이다. 둘 다 개인 사례로만 쓴다. `adjacent`는 인접 직무, `limited`는 일부 경로만 참고 가능한 제한된 사례, `mismatch`는 직업이 달라 제외할 사례다. `adjacent`·`limited`를 해당 직업의 사실 근거로 일반화하지 않고 `mismatch`는 검색에서 제외한다. 검토 전 후보는 자동으로 사실 근거에 넣지 않는다. 관련 자격이 있다는 이유로 법적 필수 자격이라고 설명하지 않는다. 지표의 원출처 직업이 현재 카드와 다르면 동일 직무로 단정하지 않는다.

게임 상황 예시는 실제 발생한 사건이 아니라 조사한 업무를 바탕으로 만든 창작이다. 명시한 출처에서 확인되지 않은 스태프 기간·급여 공제·신입 업무·승진 기간 등은 만들어 채우지 않는다. 가상 장면을 통해 직업의 핵심을 경험하게 하며 실제 사람의 적성이나 능력을 진단하지 않는다.

## 진행 기준

공식 상세 재확인, 추가 출처 확보, 수작업 검토, 심화조사 완료를 별도로 센다. 완료는 핵심 업무·준비 경로·신입/숙련 업무의 근거 또는 조사 한계·현장 상황·출처 검토가 갖춰진 직업만 인정한다. 현재 숫자는 `progress.json`을 따른다. 수집 자료가 있어도 심화조사가 끝났다고 보고하지 않는다. #341–552의 인터뷰 후보 152건은 원문 본문을 확인하고 직업과의 관계를 분류했으며, 개별 분류와 AI용 요약은 각 후보의 `body_review`에 둔다. 인터뷰 원문 캐시는 저장소에 포함하지 않는다.

공식 출처: 커리어넷 직업백과 및 직업인인터뷰. 원출처와 게시일/확인 시점을 각 레코드에 유지한다. 인터뷰 원문 전체와 동영상은 배포 파일에 복제하지 않고 링크와 질문 주제만 남긴다.
