> 출발점: [../00-idea.md](../00-idea.md)

## 들어가는 문서

> **시나리오 작가 담당.** 파일 이름 · 역할은 백엔드와 약속한 것이다 ([10-prompt-assembly.md 1절](../development/10-prompt-assembly.md#1-콘텐츠-파일-읽기-규칙)). 파일을 추가 · 삭제 · 이름 변경하면 이 표와 10 의 1절을 함께 고친다.
> 백엔드는 아래 "AI 요청" 이 ✅ 인 파일을 매 요청마다 그대로 AI 에 보낸다. 게임이 범위를 벗어나지 않게 하는 틀(하네스)이다.

| 파일 | 내용 | AI 요청 |
|------|------|:---:|
| `00-guidelines.md` | 가이드라인 (세이프가드) — **필수** | ✅ |
| `01-world.md` | 세계관 · 배경 · 톤 | ✅ |
| `02-game-scenario.md` | 게임 흐름 · 분기 · 3D 분기 판단 기준 · 결말 조건 | ✅ |
| `03-rules.md` | 최신 규칙 문서 안내 | ✅ |

| `05-npc.md` | 주변 인물 생성 · 관계 · 기억 | ✅ |

## 작성 규칙

- **문서 링크**: 게임 규칙이 기능이 되면 `development/features.md` 의 기능 번호(예: `BE5`)를 적어 연결한다
- **프롬프트 위치**: 코드가 실제로 읽어 쓰는 프롬프트 파일은 문서가 아니라 리소스라 소스 폴더에 둔다. 이 폴더에는 그 프롬프트의 **의도 · 변경 이유 · 버전 기록**을 남긴다
- **버전 기록**: 프롬프트·밸런스 값을 바꾸면 지우지 말고 날짜와 이유를 덧붙인다 (무엇이 왜 달라졌는지 추적)
- 미정 사항은 `development/11-open-issues.md` 에 올려 함께 관리한다
