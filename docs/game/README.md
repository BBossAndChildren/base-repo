# 게임 콘텐츠 문서

> 이 폴더는 **게임 안의 내용**(무엇을 플레이하는가)을 다룬다. 구현 방법(API·DB·화면)은 [../development/](../development/FILL-GUIDE.md) 에 둔다.
> 출발점: [../00-idea.md](../00-idea.md)

## 들어가는 문서 (예정)

> 아직 구성이 확정되지 않았다. 아이디어가 구체화되면 아래 표를 실제 파일 목록으로 고친다.
> 파일을 추가·삭제하면 **이 표를 함께 고친다** — 협업자가 이 표만 보고 무엇이 어디 있는지 알 수 있어야 한다.

| 파일 (예시) | 내용 |
|-------------|------|
| `01-world.md` | 세계관 · 배경 설정 · 톤 |
| `02-game-scenario.md` | 게임 진행 시나리오 · 단계 · 분기 |
| `03-rules.md` | 게임 규칙 · 점수 · 승패 조건 · 밸런스 값 |
| `04-prompts.md` | AI 프롬프트 설계: 목적 · 입력 · 기대 출력 · 금지 사항 · 버전 기록 |

## 작성 규칙

- **문서 링크**: 게임 규칙이 기능이 되면 `development/features.md` 의 기능 번호(예: `B3`)를 적어 연결한다
- **프롬프트 위치**: 코드가 실제로 읽어 쓰는 프롬프트 파일은 문서가 아니라 리소스라 소스 폴더에 둔다. 이 폴더에는 그 프롬프트의 **의도 · 변경 이유 · 버전 기록**을 남긴다
- **버전 기록**: 프롬프트·밸런스 값을 바꾸면 지우지 말고 날짜와 이유를 덧붙인다 (무엇이 왜 달라졌는지 추적)
- 미정 사항은 `development/11-open-issues.md` 에 올려 함께 관리한다
