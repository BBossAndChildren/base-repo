## B. 팀 · 협업 규칙 불일치
| # | 내용 | 결정 |
|---|------|------|
| B1 | **실시간 이벤트 전달이 명세 v001 에서 선택 기능이다.** 명세의 기본 방식은 시작 호출 → 종료 호출 → `experience.ended` 한 번에 과정·결과를 묶어 받는 것이고, 개별 행동 이벤트는 Unity 내부에 보존한다 (`docs/unity/PROTOCOL-SNAPSHOT.md` "프론트 방별 호출·체험 종료 응답 프로필"). 안 A(상호작용마다 즉시 전달)를 하려면 Unity 가 이 선택 기능(물건 상태가 바뀔 때마다 이벤트 송신)을 구현해야 한다. Unity 담당이 상태가 바뀔 때마다 실시간 전달이 되는지 **검토 중** | |
| B2 | **시작 호출에 에셋을 지정하는 필드가 없다.** 명세의 시작 호출은 `roomId` · `scenarioId` · `scenarioVersion` 만 받는다. 같은 사무실 빌드라도 직업에 따라 다른 에셋을 불러와야 하므로, AI 가 추천한 에셋을 Unity 에 어떻게 전달하는지 (scenarioId 로 구분하는지, 새 필드를 추가하는지) Unity 담당에게 **문의 중** | |
