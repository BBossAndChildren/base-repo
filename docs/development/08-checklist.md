## 3. 출시 · 발표 당일 체크리스트
- [ ] GPU 서버: 게이트웨이 · Django(Gunicorn) · PostgreSQL (`docker compose ps` 모두 healthy) · AI API(`pgrep -af uvicorn`) · 중계기(`docker ps` 의 `ai-relay`) · 터널(`pgrep -a cloudflared`)이 실행 중
- [ ] 터널 주소가 Vercel 환경변수와 같다 (바뀌었으면 재배포)
- [ ] AI 서버 응답 확인 (L6 대표 입력 1개)
- [ ] 시연할 3D 체험을 미리 한 번 끝까지 해 봄
- [ ] VPN 을 끈 기기에서 처음부터 끝까지 한 번 플레이
- [ ] 시연 영상 · 발표 자료 제출 ([final-checklist.md](../final-checklist.md))

## 상세 기획 갱신 범위 (2026-10-31)

최신 요구사항은 [게임 상세 기획](../game/06-life-career-design.md)과 [features 8절](features.md#8-상세-기획-반영-범위-2026-10-31)을 따른다. 원화 자금·빚·건강·스트레스·주거/성장 표시, NPC별 기억, 멱등 턴 및 일시정지는 후속 구현 범위다. 기존 FE4의 일부 구현 표시를 전체 상태 연동 완료로 해석하지 않는다.
