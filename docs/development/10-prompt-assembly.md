## 4. 3D 빌드 · 에셋 추천

> 흐름 원문: [00-idea.md 12. 서비스 구조](../00-idea.md#서비스-구조-회의-결정)

1. 3D 가 필요한 분기에 도달하면 백엔드가 빌드·에셋 정보 JSON 을 정리해 AI 서버에 추천을 요청한다
2. AI 서버는 빌드와 에셋을 추천한다
3. 백엔드는 추천이 정보 JSON 에 있는지 확인하고, 빌드 파일과 에셋 정보를 그대로 프론트에 보낸다
4. 맞는 빌드가 없거나 정보 JSON 에 없는 빌드·에셋이면 3D 를 건너뛰고 텍스트로 계속한다 (프론트는 모달·토스트로 안내, `alert` 금지)
5. 체험 결과값(선택 · 성과)은 프론트 → 백엔드로 받아 다음 프롬프트에 넣는다
