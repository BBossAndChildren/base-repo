## 4. 3D 빌드 · 에셋 추천

> 흐름 원문: [00-idea.md 12. 서비스 구조](../00-idea.md#서비스-구조-회의-결정)

1. 3D 가 필요한 분기에 도달하면 백엔드가 빌드·에셋 정보 JSON 을 정리해 AI 서버에 추천을 요청한다
2. AI 서버는 빌드와 에셋을 추천한다
3. 백엔드는 추천이 정보 JSON 에 있는지 확인하고, 빌드 파일과 에셋 정보를 그대로 프론트에 보낸다
4. 맞는 빌드가 없거나 정보 JSON 에 없는 빌드·에셋이면 3D 를 건너뛰고 텍스트로 계속한다 (프론트는 모달·토스트로 안내, `alert` 금지)
5. 프론트가 Unity 에 체험 시작을 호출하고, 체험 중 Unity 응답을 받을 때마다 빌드·에셋 정보를 덧붙여 즉시 백엔드로 보낸다 (4-3)
6. 체험이 끝나면 백엔드가 쌓인 결과를 플레이어 기록에 한 번 반영하고 다음 프롬프트에 넣는다

### 4-2. 체험 결과값 형식 (Unity → 프론트)

> **원본: [`docs/unity/`](../unity/README.md) — career-experience v001.** Unity 담당이 관리하는 명세이며 이 문서에 다시 쓰지 않는다. 바뀌면 Unity 담당이 새 버전 패키지로 다시 전달한다.
> 상태: **명세만 있음.** Unity 송신 브리지 · 프론트 수신 어댑터 · 실제 왕복 통신은 아직 구현·검증 전이다 (`docs/unity/MANIFEST.json`).

| 응답 | 의미 | 백엔드가 쓰는 곳 |
|------|------|------------------|
| `experience.started` | 방·시나리오 준비 완료 | 체험 시작 기록 |
| `experience.ended` | 체험 종료. `result.outcome` 이 `completed` · `aborted` · `failed` 중 하나 | 플레이어 기록 반영 (과정 `process` · 결과 `result` · 해석 `context`) |
| `experience.error` | 호출·라우팅 오류. 업무 실수가 아님 | 체험 종료 → 텍스트 모드 전환 |

백엔드가 결과를 해석할 때 지킬 것 (명세 원문 기준):
- 카운트가 `null` 이면 미측정이다. 0회로 해석하지 않는다
- 평가 코드(`TASK_SMOOTH` 등)는 이번 가상 업무의 수행 설명이며 개인의 적성·능력 점수가 아니다. AI 프롬프트에도 그렇게 전달한다
- 중도 종료(`aborted`)여도 이미 완료한 결과는 `result.data.partialResults` 에 남는다
- 탭 강제 종료 · 통신 단절은 마지막 응답이 보장되지 않으므로 사용자 포기로 단정하지 않는다

### 4-3. 프론트 → 백엔드 전달

- 프론트는 Unity 응답을 **받을 때마다 즉시** 백엔드로 보낸다. 덧붙이는 값: 체험한 빌드 · 에셋 정보
- 묶음 ID 는 Unity 명세의 `sessionId` · `experienceId` 를 그대로 쓴다 (`experienceId` 는 체험을 시작할 때 프론트가 생성)
- 중복은 `eventId`, 순서는 `sequence` 로 백엔드가 정리한다. 보내기에 실패한 응답은 프론트가 다시 보낸다
- 백엔드는 이벤트를 쌓기만 하다가 `experience.ended` 를 받으면 한 번 플레이어 기록에 반영한다. 종료 응답이 오지 않으면 <!-- TODO: 처리 시점 (다음 재개 시 · 일정 시간 후) --> 그때까지 받은 이벤트로 "중간에 그만둠" 처리한다

### 4-4. 오류 안내 문구

| 상황 | 방식 | 문구 |
|------|------|------|
| 맞는 빌드가 없음 · 추천이 목록에 없음 | 토스트 | 지금 상황에 맞는 3D 체험이 없어 텍스트로 이야기를 이어갈게요. |
| 빌드 로딩 실패 | 토스트 | 3D 체험을 불러오지 못했어요. 이번 체험은 건너뛰고 텍스트로 이어갈게요. |
| 체험 중 `experience.error` · 명세에 맞지 않는 값 · 내부 오류 | 모달 + [텍스트로 계속하기] | 체험 중 문제가 생겨 3D 체험을 종료했어요. 지금까지 한 체험은 저장되었어요. 텍스트 모드로 이어서 진행해 주세요. |
