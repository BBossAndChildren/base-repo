## 열람 방법

GitHub에서는 Markdown과 PDF를 바로 읽을 수 있습니다. HTML은 사이트처럼 실행되지 않으므로 **ZIP 파일을 다운로드한 뒤 압축을 풀고 `열람본.html`을 브라우저에서 여세요.** HTML 파일만 내려받아도 본문·이미지·양식·PDF 다운로드를 오프라인으로 사용할 수 있습니다. 외부 출처 링크는 인터넷 연결이 필요합니다.

## 원본 보존과 갱신 기준

PDF 두 개는 내용·파일명·내부 메타데이터를 수정하지 않았습니다. PDF 단독 파일, HTML에 내장된 다운로드, ZIP 내부 파일이 같은 원본인지 SHA-256으로 확인했습니다. 나머지 배포 파일도 로컬에서 검증한 산출물과 같은 바이트로 추가했습니다.

다음 갱신은 단일 Markdown을 기준으로 HTML·ZIP·무결성 기록을 함께 맞춥니다. PDF 원본은 편집하지 않습니다. 이 묶음은 팀 내부 작업 문서이며 공식 제출용 소스 저장소 구성이나 대회 제출 완료를 뜻하지 않습니다.
