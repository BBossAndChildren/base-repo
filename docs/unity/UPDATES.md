# 직업 체험 업데이트 v002 — 효과음·배경색·AI 설명

이번 전달은 ① 테스트 실행 링크, ② 실제 연동용 WebGL ZIP, ③ 리스팅·프론트/백엔드 연동 자료 ZIP으로 구성합니다. ZIP 파일은 두 개이며 기존 결과물은 보존합니다.

## 추가·변경 사항

- 기존에 만든 ElevenLabs 효과음을 재사용하는 재생기를 연결했습니다. 음소거·볼륨·재생 중지 설정, 브라우저의 최초 사용자 조작 확인, 중복 재생 제한, 동시 재생 수 제한, 종료·초기화·다른 실행의 늦은 재생 차단을 포함합니다.
- 테스트 화면에는 효과음 목록과 미리듣기가 있습니다. 실제 파일이 있는 항목과 미생성 항목을 구분합니다. 파일 포함, 소스 연결, 실제 게임 재생 확인은 각각 별도로 기록합니다.
- 현재 108종 중 34종의 파일을 확보했습니다. 기존 32종은 그대로 보존했고, 사용자의 생성 승인 후 SFX-012·013 두 종을 추가했습니다. 이후 사용자가 요청한 **추가 비용 없음** 조건에 따라 추가 유료 생성과 업그레이드는 하지 않습니다. 나머지 74종은 서비스의 생성 제한으로 미생성 상태입니다. 다른 소리로 바꾸어 108종 생성 완료로 표시하지 않습니다.
- 확보된 34종 가운데 30종은 실제 업무 동작과 연결된 소스가 있고, 4종은 미리듣기·재사용 자료로 포함됩니다. 파일이 없는 10개 동작 키는 조용히 생략합니다. 전체 108종이 실제로 게임에서 재생된다는 뜻이 아닙니다.
- 외부 프론트에서 WebGL 내부 배경색을 `#RRGGBB` 값으로 지정할 수 있습니다. 방 전환과 초기화에도 설정을 유지합니다. 중간 빌드 검수에서 발견한 화면 바깥 여백의 색상 누락도 수정하고, 밝은 배경에서 안내 글자가 흐려지지 않도록 패널에 불투명한 바탕을 넣었습니다. 모델 색상·공용 팔레트는 변경하지 않습니다. 투명 배경은 이번 기능에 포함되지 않습니다.
- 555개 방별 체험 조합에 `jobs` 문자열 배열과 실제 업무를 설명하는 `description`을 추가했습니다. 552개 시나리오 ID와 71개 공간을 포함하며 성직자의 세 공간 설명도 각각 구분합니다. 원문의 직업 이름만 보고 내용을 추측하지 않고 현재 구현된 단계·입력·배치·조절·인계 작업을 근거로 작성했습니다.
- 카드 목적지에 작성된 실제 이름을 표시하도록 고쳤습니다. 이전의 일괄적인 “1번 자리” 표시는 이름이 없는 항목의 대체 표시에만 사용합니다.
- 카드를 끌거나 선택했을 때 놓을 수 있는 칸에 테두리와 안내를 표시하고, 포인터 아래 칸을 더 강하게 강조합니다. 놓인 카드에는 `✓ 배치됨`과 배치 개수가 남습니다. 이 표시는 물건을 놓았다는 뜻이며 정답·저장 성공은 별도의 검토·저장으로 확인합니다.
- 저장 결과 알림의 제목과 본문을 서로 다른 영역에 배치하고 여백·줄바꿈·높이를 조정했습니다. 긴 결과 문장에는 스크롤 영역을 적용하고 카드 안내 문구와 저장 버튼이 겹치지 않도록 위치를 조정했습니다.

## 프론트 적용

```jsx
<Experience
  siteUrl="/career-webgl/index.html"
  manifest={manifest}
  sessionId={sessionId}
  backgroundColor="#F4F1EA"
  onClient={client => { clientRef.current = client; }}
/>
```

실행 중 변경은 `clientRef.current.setPresentation({ backgroundColor: '#DCECF4' })`로 요청합니다. 시작·종료 요청 및 학습 과정 기록과 분리된 표시 설정이며 색은 불투명한 6자리 16진수만 받습니다. 프론트의 페이지 바깥 배경은 해당 페이지의 CSS로 별도 지정합니다.

게임 소리를 처음 켜려면 게임 화면 안을 클릭하거나 효과음 활성화 버튼을 누릅니다. 외부 React 화면에서 시작 버튼을 눌렀다는 사실만으로 모든 브라우저가 iframe 소리 재생을 허용하는 것은 아닙니다. 효과음 파일은 `site/audio/`에서 같은 출처로 제공하므로 런타임 음성 생성 API나 키가 필요하지 않습니다.

AI 선택기는 해당 배포의 `site/ai-build-catalog.json` 또는 `site/supported-manifest.json`에서 `buildId + roomId + scenarioId + scenarioVersion`을 함께 대조합니다. `description`은 체험 내용 설명이며 사용자의 적성·자격·전문 능력 판정 자료가 아닙니다.

```json
{
  "scenarioId": "career-net-951-experience",
  "jobs": ["행사기획자"],
  "description": "행사 요청서의 행사명·날짜·인원을 입력하고, 안내·발표·체험 일정 카드를 배치한 뒤 담당자 인계 메모를 작성하는 체험입니다."
}
```

위 코드는 설명 형식을 보여 주는 예시입니다. 정확한 배포 문장과 ID·버전은 동봉한 전체 JSON·CSV를 기준으로 합니다.

## 전달 자료

- 실제 연동 ZIP: `site/`, `manifest.json`, `BUILD.md`, `README.md`, `UPDATES.md`.
- 리스팅 ZIP: 555개 체험의 ID·직업·설명 JSON/CSV, 효과음 108종의 파일·해시·사용 위치·상태 목록, 프론트/백엔드 어댑터·타입·연동 예제, 규격 스냅샷, 실제 검수 기록, `UPDATES.md`.
- Unity 편집 프로젝트와 모델 원본은 WebGL ZIP에 넣지 않습니다. 각 소리의 원본과 가공본은 정식 저장소에서 보존합니다.

## 검수와 남은 범위

최종 테스트 `career-suite-test-v009`와 실제 연동 `career-suite-integration-v005`는 Unity에서 오류 0건·경고 0건으로 빌드했습니다. 새 테스트에서 경찰관 PAN-050 체험을 실제 3D 물건 선택 세 번, 카드 드래그 여섯 번, 한국어 입력으로 완주했습니다. 제출 3회·실수 0회·재시도 0회이며, 배치 표시·닫기/재열기 보존·저장 결과 제목/본문 분리·일시정지/종료 소리 정리와 원본 이벤트 37개의 로컬 ACK를 확인했습니다.

최종 실제 연동 빌드에서는 React 시작/종료, 크림색·파란색의 전체 화면 배경과 방 전환 후 유지, 불투명 안내 패널, 실제 효과음 재생과 종료 정리를 확인했습니다. 원본 이벤트 29개에 로컬 ACK 29개가 대응했습니다. 요청한 파란색 `#DCECF4`의 캡처는 `#DBECF4`로 렌더링돼 8비트 한 채널에서 1만큼의 반올림 차이가 있었으며, 배경 범위는 전체 캔버스에 일치했습니다.

34개 파일 전체의 실제 Web Audio 디코드·시작·종료 검사는 중간 빌드 v003에서 통과했고, 최종 두 빌드에도 같은 파일과 오디오 재생기 바이트가 포함됐음을 대조했습니다. 최종 테스트의 실제 업무 재생과 전체 라이브러리 미리듣기는 별도 증거입니다. 스피커의 물리적 출력 청취나 모든 업무에서 30개 연결 음을 각각 재생한 검수는 주장하지 않습니다. 최종 압축파일의 무결성·압축 해제 후 실행 검수는 전달 안내와 리스팅의 패키지 근거에 기록합니다.

추가 471개는 기본 체험 미션입니다. 기존 원문 특수분기 554건, 모든 555개 조합의 완주 검수, 실제 서비스의 인증·저장·lease·복구 연동은 이번 효과음/설명 추가로 완료되지 않습니다. 기존 사무실 계열의 종료 뒤 탐색 원본 이벤트와 얇은 물건의 포인터 선택 한계는 기존 검토 기록을 유지합니다.

비용은 과거 효과음 제작 비용과 이번 두 종의 도구 보고 10크레딧을 구분합니다. 실제 청구서·추가 결제 여부는 확인하지 않았습니다. 최신 비용 조건 이후 추가 유료 생성은 하지 않았습니다. 이번 모델·이미지 생성 호출과 Meshy 크레딧은 0이며 실제 토큰 사용량은 미측정입니다.
