# 프론트·백엔드 연동 v003

`web/career-preview/v003`는 기존 v002를 보존한 새 어댑터입니다. Unity의 과정 이벤트 봉투와 카운트 계약을 유지하면서 별도 표시 설정과 효과음 재생을 추가합니다.

## 배경색

React `Experience`의 `backgroundColor="#F4F1EA"` 또는 `client.setPresentation({ backgroundColor: '#DCECF4' })`를 사용합니다. 불투명한 `#RRGGBB`만 허용합니다. 설정은 방 전환과 초기화에도 유지하며 게임 과정 이벤트로 집계하지 않습니다. 페이지 바깥 배경은 호스트 CSS에서 지정합니다.

## 효과음

`audio.js`는 `site/audio/audio-manifest.json`의 동봉 파일을 Web Audio로 재생합니다. 실제 사용자 입력으로 브라우저 재생 제한을 해제하며, 음소거·볼륨·종료·일시정지·초기화·지연 재생 취소를 지원합니다. `audio-ui.js`는 설정 UI와 테스트 화면의 전체 목록·미리듣기를 제공합니다. API 키나 런타임 생성 요청은 사용하지 않습니다.

108종 중 실제 파일 34종, 미생성 74종입니다. 30종은 게임 동작에 연결된 소스가 있으며 4종은 미리듣기·재사용 라이브러리입니다. 재생할 파일이 없는 동작 키는 조용히 생략합니다. 파일·소스 연결·실제 재생 검수는 서로 다른 상태입니다. 잠금 해제 전이나 음소거 중 시작된 반복음은 작업 화면을 다시 열어야 새로 시작될 수 있습니다.

## 체험 선택

해당 배포의 `ai-build-catalog.json`과 `supported-manifest.json`에는 555개 공간별 체험의 `jobs` 배열과 `description`이 있습니다. `buildId + roomId + scenarioId + scenarioVersion` 전체로 식별합니다. 성직자의 등록된 세 공간도 각각 고유 조합으로 선택합니다. 설명은 현재 구현된 교육 체험의 실제 업무 요약이며 적성·자격 판정이 아닙니다.

## 저장 수신기와 검수

`server.mjs`는 로컬 HTTP·파일 저장 ACK 예제입니다. 실제 서비스의 인증, 사용자 소유권, lease, fencing, 재연결 복구는 제공된 계약이 없어 운영 연동으로 검증하지 않았습니다. `client.js`, `backend.js`, 각 타입 선언과 `Experience.jsx`를 참고해 실제 서비스에 연결합니다.

실제 빌드별 검증은 [최신 전달 안내](../builds/career-suite-v002.md)와 해당 빌드의 근거를 따릅니다. 격리된 상태 검사와 이전 버전의 통과 기록을 새 버전 전체 검증으로 승계하지 않습니다. 기존 종료 후 늦은 탐색 원본 이벤트는 보존하되 종료된 결과 스냅샷은 변경하지 않습니다.
